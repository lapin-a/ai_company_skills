1. **ACN 상장주식수는 Class A만 센다.** Class X는 상장 주식이 아니고 전환비율도 원문에서 확인되지 않는다(미확인). 라운드 2 V 규칙과 같은 판단이다.
   - 출처 열에 "Class A만, Class X 제외"를 적고, 검산 열에 클래스별 주식수를 남긴다.
   - Class X는 30만 주로 Class A의 0.05% 수준이라 시가총액에 미치는 영향은 작다.
2. 나머지는 라운드 1~4 규칙 그대로다. **새 규칙은 이 하나뿐이다.**
