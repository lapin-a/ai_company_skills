## 5. 발견 — 재작성 검증 실패 시 지배지분 자본만 재작성값으로 섞임 (수정 완료)

ROL 2019Q4: 총자본 815,750,000(원 공시, `비지배 없음`)인데 지배지분 자본은 833,109,000(재작성 반영). 비지배가 없는 회사인데 두 값이 다르다 → 확정 규칙 "총자본 = 지배지분 자본 + 비지배지분" 위반.

- 원인: `collect_us_round1.restate_rows`가 칸마다 따로 고른다. 재작성 세트에서 대차 검증이 실패하면 자산·부채·총자본은 미확인이 돼 원 공시로 되돌아가지만, 지배지분 자본은 미확인 표시가 안 돼 재작성값이 그대로 들어간다.
- 전수 스캔: **47칸** (라운드 5·7·8·9·11·12·13·14·15·21·28 기존 42칸 + 이번 ROL 5칸). 예: EBAY 2025Q1 암시 비지배 0 → 121M, LH 2019Q4 0 → −76.9M, CMI 2021Q4 927M → 1,255M.
- 고치는 안: 한 분기의 저량 4항목(자산·부채·총자본·지배지분 자본) 중 하나라도 재작성 검증 실패면 네 칸 모두 원 공시로 되돌린다. 공용 코드 수정이라 라운드 1~31 회귀가 따라붙는다.
