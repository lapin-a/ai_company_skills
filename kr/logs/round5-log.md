## 0. KRX API 키 확인 (자동화 운영팀, 2026-09-20)

대표가 `.claude/settings.local.json`의 `env.KRX_API_KEY`를 등록했다(40자). 2019년 시장데이터 372칸을 채울 수 있는지 시험했다.

| 엔드포인트 | 헤더 | 결과 |
|---|---|---|
| `data-dbg.krx.co.kr/svc/apis/sto/stk_bydd_trd` | `AUTH_KEY` | HTTP 401 `Unauthorized API Call` |
| 같은 주소 | `authKey` | HTTP 401 `Unauthorized Key` |
| `sto/ksq_bydd_trd` · `sto/knx_bydd_trd` · `idx/krx_dd_trd` · `idx/kospi_dd_trd` · `sto/stk_isu_base_info` · `etp/etf_bydd_trd` | `AUTH_KEY` | 모두 HTTP 401 `Unauthorized API Call` |

- 헤더 이름은 `AUTH_KEY`가 맞다(다른 이름은 "Unauthorized Key"로 응답이 다르다). 즉 **키 형식은 인식되는데 API 사용 권한이 없다.**
- 추정(미확인): KRX 오픈API는 API별로 사용 신청·승인이 필요하다. 승인 전이거나 다른 서비스의 키일 수 있다.
- **결론: 2019년 시장데이터 372칸은 아직 채울 수 없다.** 이번 라운드도 `데이터 없음(소스 서비스 시작일 2020-01-02 이전)` 규칙 그대로 간다.
- 대표 확인 사항: KRX 오픈API 포털에서 해당 API 사용 신청이 승인됐는지 확인이 필요하다.
- **후속(2026-09-21): 7개 엔드포인트 모두 HTTP 200으로 바뀌었다.** 2019년 시장데이터 567칸을 채웠다. 상세 [krx-backfill-log.md](krx-backfill-log.md).
